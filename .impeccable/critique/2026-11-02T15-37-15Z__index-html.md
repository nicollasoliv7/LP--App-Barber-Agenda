## Priority Issues

### P0 — Static HTML h1 makes a false product claim (H5)
**File:** index.html line 2145
**Snippet:** `<h1 id="hero-titulo">O cliente marca sozinho. <span ...>A mensalidade atrasada é cobrada automaticamente pelo app.</span></h1>`

The static h1 claims the app charges overdue subscriptions automatically. This is explicitly false — two inline disclaimers on the page say "o Agendou não faz cobrança automática no cartão nem débito recorrente de mensalidades." JS replaces this with variant B at runtime, but:
- No-JS users and screen readers during FOUC see the false claim
- Googlebot may index the static HTML before JS execution
- Creates legal/trust risk if cached or screenshotted

**Fix:** Replace static h1 content with variant B text. JS A/B override still works; fallback becomes honest.
